# Teacher User Guide

## 1. Starting an Attendance Session
1. Sign in with teacher credentials.
2. Select your assigned class and subject from **Today's Classes**.
3. Click **Start Dynamic QR Session**.
4. The system opens the full-screen classroom projector display.

## 2. Classroom Projector Display
- Displays a high-contrast rotating QR code updating automatically every 15 seconds.
- Displays an ephemeral 6-digit challenge code beside the QR code.
- Shows an animated countdown timer.
- Real-time registered students list updates as students scan.

## 3. Manual Verification & Session Closure
- During the initial 14-day window or when an attendance attempt is flagged for elevated risk, records transition to **Pending Confirmation**.
- Click **Confirm Present** or **Reject** with a recorded audit note.
- When the registration window concludes, click **Close & Finalize Session**. All unrecorded enrolled students are automatically finalized as **Absent**.

## 4. Offline Attendance
- If internet connectivity drops, your downloaded class roster remains accessible.
- Mark students present, late, or absent locally.
- When connectivity resumes, click **Synchronize Now** in the top navigation bar.
